02 / LOGIC ARCHITECTURE

How the circuit is wired

The mode line controls four XOR gates and the first carry input. Four full adders then form a ripple-carry chain.

Data path Mode control Carry path
ƒ

Key idea: XOR acts as a controlled inverter. When M = 0, B passes unchanged. When M = 1, every B bit is complemented and the initial carry adds the required +1.

03 / WORKING PRINCIPLE

The logic behind it

The same full-adder chain handles both operations. Only the B input conditioning and the initial carry-in change.

01 · MASTER EQUATION

Unified arithmetic

S = A + (B ⊕ M) + M

For each bit, XOR either preserves or complements B. The mode bit is also connected to the least-significant carry input.

03 · FULL ADDER

Per-bit equations

Xᵢ = Bᵢ ⊕ MSumᵢ = Aᵢ ⊕ Xᵢ ⊕ CᵢCᵢ₊₁ = AᵢXᵢ + Cᵢ(Aᵢ ⊕ Xᵢ)

Each carry output becomes the next stage's carry input.

04 · STATUS FLAGS

Interpreting the result

  • Carry: final carry-out from FA₃.
  • Borrow: for unsigned subtraction, Borrow = NOT(Carry-out).
  • Overflow: carry into MSB XOR carry out.
  • Zero: 1 when all four result bits are 0.

The 4-bit result is modulo 16. Signed overflow is meaningful under two's-complement interpretation.

PROJECT TAKEAWAY

Subtraction is addition in disguise.

By using two's complement, the circuit reuses the same full adders for both arithmetic operations. This reduces hardware duplication and demonstrates a core idea used in arithmetic logic units.

ADDA + B↔SUBTRACTA + ~B + 1
